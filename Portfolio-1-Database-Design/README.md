## Case Study

## Portfolio Overview

This portfolio focuses on the conceptual and logical design of the Apex Digital Bank database system. 
It demonstrates the application of database design principles, including entity identification, relationship modelling, 
key definition, data integrity constraints, and normalization to support a scalable and efficient banking database solution.

---

## Expected Evidence

- Case Study Description
- Entity Relationship Diagram (ERD)
- Relational Schema
- Primary Keys and Foreign Keys
- Data Integrity Constraints
- Database Normalization (1NF, 2NF, and 3NF)

---

## Deliverables

### 1. Case Study Analysis
Analysis of the Apex Digital Bank business requirements and data needs.

### 2. Entity Relationship Diagram (ERD)
Development of a conceptual data model showing entities, attributes, relationships, and cardinalities.

### 3. Relational Schema
Conversion of the ERD into a logical relational database structure.

### 4. Data Integrity Constraints
Definition of primary key, foreign key, unique, domain, NOT NULL, and business rule constraints.

### 5. Database Normalization
Evaluation of the database design against First Normal Form (1NF), Second Normal Form (2NF), and Third Normal Form (3NF).
