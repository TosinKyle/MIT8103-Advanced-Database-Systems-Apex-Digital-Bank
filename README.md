## Project Overview

This repository contains all portfolio submissions developed for the MIT 8103 Advanced Database Systems module using the Apex Digital Bank case study. The project demonstrates the application of advanced database design principles and industry best practices in developing a secure, scalable, and efficient relational database system for a modern digital banking environment.

The database solution is designed to support core banking operations including customer management, Know Your Customer (KYC) verification, account administration, transaction processing, card management, loan services, branch operations, employee management, and audit logging.

## Repository Purpose

This repository serves as a central location for all artefacts, documentation, implementation scripts, screenshots, execution plans, and technical evidence produced throughout the MIT 8103 Advanced Database Systems portfolio activities. It demonstrates progressive development, practical implementation, and continuous learning across all five portfolio components.

## Project Objectives

The primary objectives of this project are to:

- Analyse the business and data requirements of Apex Digital Bank.
- Design a conceptual database model using Entity Relationship Diagrams (ERDs).
- Develop a logical database structure through relational schemas, keys, and relationships.
- Apply integrity constraints and normalization techniques up to Third Normal Form (3NF) to improve data quality and consistency.
- Implement the database using Structured Query Language (SQL).
- Optimise database performance through query analysis, indexing, and execution plan evaluation.
- Demonstrate transaction management and concurrency control mechanisms to ensure data reliability.
- Design and evaluate NoSQL data models suitable for banking operations and scalable data storage.
- Examine distributed and cloud database concepts, including replication, sharding, consistency, and availability.
- Explain the practical application of advanced database management concepts within the Apex digital banking environment.
